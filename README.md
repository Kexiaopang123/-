# 🚁 项目名称 (无人机手势识别控制)

本项目主要涉及基于树莓派和无人机的开发（如手势识别控制等）。以下是本项目所需的硬件清单与软件环境配置指南，包含了一些实用的避坑建议。

## 🛠️ 硬件环境 (Hardware)

* **核心主控**：**树莓派 5B (Raspberry Pi 5B)**
    * *说明*：5B 的算力对于本项目的需求已经完全够用。
* **视觉输入**：**普通 USB 摄像头**
    * > ⚠️ **避坑指南**：强烈建议随意购买一个市面上能用的免驱 USB 摄像头即可。**千万不要使用树莓派自带/原装摄像头**，其配置过程非常繁琐且实际体验不佳。
* **无人机平台**：**01studio**（或类似产品）
    * > 💡 **重要建议**：本项目目前使用的是 01studio 无人机，但该型号**缺少光流模块**，导致在进行手势识别等控制操作时，飞行姿态极不稳定。强烈建议复现本项目的开发者**更换为带有光流模块的无人机**，以保证良好的悬停和飞行稳定性。

---

## 💻 软件环境 (Software)

* **编程环境**：**Thonny**
    * 轻量级的 Python IDE，非常适合用于树莓派的开发与调试。
* **远程桌面连接**：**VNC Viewer**
    * 用于通过网络远程连接并显示树莓派的可视化桌面。
* **SSH 命令行连接**：**PuTTY**
    * 用于通过命令行（终端）轻量化远程连接树莓派。
* **文件传输**：**FileZilla**
    * 非常适合在 PC 与树莓派之间进行大批量的文件传输，支持便捷的拖拽操作。
