# 树莓派无人机手势控制系统

本项目实现了一套基于树莓派视觉的手势控制无人机系统。通过摄像头捕捉手部动作，提取几何特征识别手势，并通过低功耗蓝牙（BLE）实时控制无人机飞行。后续想优化首先是硬件无人机一定要选好，其次代码部分根据你的要求调整

## 硬件说明

* **核心主控**：树莓派 5B（算力已满足本项目的实时推理需求）
* **视觉输入**：普通免驱 USB 摄像头
  > 注意：请随意购买市面上可用的 USB 摄像头即可。不要使用树莓派自带摄像头，其配置极其繁琐且实际体验不佳。
* **无人机平台**：01studio（或支持 BLE 串口透传的类似微型无人机）
  > 注意：01studio 此款无人机缺少光流模块，手势控制时悬停和飞行姿态很不稳定。建议复现本项目的开发者更换为带有光流模块的无人机。

## 软件与开发环境

* **编程环境**：Thonny
* **远程连接**：
  * VNC Viewer（用于连接树莓派桌面，查看摄像头可视化画面）
  * PuTTY（用于 SSH 命令行连接树莓派）
* **文件传输**：FileZilla（适合 PC 与树莓派间的批量文件传输或拖拽操作）

## 代码结构

系统采用多进程架构，将高 CPU 负载的视觉处理与高 I/O 敏感的蓝牙通信分离，消除进程间阻塞以降低延迟。

* `main.py`
  项目入口文件。负责初始化多进程架构，拉起视觉引擎与通信引擎，通过 `multiprocessing.Queue` 传递极小数据包（指令枚举）以消除 IPC 延迟。
* `vision.py`
  视觉感知进程。调用 Picamera2 获取视频流，并包含基于传统算法的相机畸变校正处理。驱动 MediaPipe 进行关键点检测，内置滤波逻辑对原始信号进行平滑处理，将稳定手势映射为飞行指令。
* `util.py`
  核心算法与工具类。定义飞行指令与手势状态机的枚举类，包含提取几何特征的核心数学逻辑（如欧氏距离计算、基于射线交叉法判定指尖是否在掌心多边形内等）。系统完全基于几何特征进行判定，未使用端到端卷积神经网络（CNN）。
* `fly.py`
  蓝牙通信进程。基于 bleak 库扫描并连接无人机，循环读取指令队列，将控制枚举封装为对应的 8 字节十六进制控制协议包，通过 BLE 持续下发给无人机。

## 模型文件

* `hand_landmarker.task`
  MediaPipe 官方提供的轻量级手部地标检测预训练模型（TFLite 格式），用于提取 21 个手部关键点的 3D 坐标数据。
